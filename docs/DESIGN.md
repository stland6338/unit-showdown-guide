# DESIGN — デザインシステム（Claude Fable 設計）

**正となる成果物: `design/mockup.html`**（トップページのデザインカンプ）。本書はそのトークンと意図の言語化。実装時に迷ったらカンプを開いて見た目を合わせること。

## コンセプト: 「作戦司令室（OPERATION HUD）」

エンドフィールドの産業系UI（工場・ハザード・計器）と、公式KVの黄×黒タクティカルを**モチーフとして再解釈**。
公式画像・ロゴ・キャラ絵は一切使わず、色・ストライプ・タイポグラフィだけで世界観を想起させる。
アルプススタンド2026 が「甲子園の電光掲示板」だったのに対し、本作は「基地のオペレーションHUD」。

## カラートークン（Tailwind `theme.extend.colors` に登録）

| トークン | 値 | 用途 |
|---|---|---|
| `carbon` | `#101114` | 地色（ページ背景） |
| `carbon-2` | `#17181d` | パネル面（カード背景） |
| `carbon-3` | `#1f2127` | 浮き面 |
| `signal` | `#F2E900` | 主役。見出し強調・ボーダー・ハザード |
| `signal-dim` | `#b8b100` | signal の抑えめ変種 |
| `chalk` | `#ECEDE8` | 本文テキスト |
| `muted` | `#8a8d94` | 補助テキスト |
| `live` | `#FF4655` | LIVE表示専用（signal と絶対に混用しない） |
| `line` | `#2c2e35` | 罫線・方眼 |

原則: **黄と黒の二色支配 + LIVE だけ赤**。色数を増やさない。ステータスは色+文字ラベル併記（色覚対応、アルプススタンド踏襲）。

## タイポグラフィ

| 役割 | フォント | 備考 |
|---|---|---|
| 英字ディスプレイ | Chakra Petch (Google Fonts, 500/600/700) | 見出し・数字。大文字+letter-spacing |
| 和文本文 | Zen Kaku Gothic New (400/500/700/900) | 見出しは 900 |
| モノスペース | IBM Plex Mono (400/600) | ラベル・日時・注記。`letter-spacing: .2em` のマイクロラベルが世界観の核 |

`next/font/google` で読み込み（セルフホスト・CLS対策）。

## シグネチャ要素（これを外すと別サイトになる）

1. **ハザードストライプ**: `repeating-linear-gradient(-45deg, signal 0 18px, carbon 18px 36px)` のセクション区切り
2. **HUDコーナーブラケット**: カード四隅の 14px L字（カンプの `.corner` 参照）
3. **ブループリント方眼**: hero背景の 48px グリッド + 微細ノイズオーバーレイ
4. **アウトライン+ベタの2段見出し**: `-webkit-text-stroke` の白抜き「UNIT」+ 黄ベタ「SHOWDOWN」
5. **カウントダウン計器**: tabular-nums の巨大数字 + モノスペース単位
6. **セクション番号**: `SEC.01` 形式のモノスペースラベル + 英大見出し + 和文小見出しの三点セット
7. **非公式スタンプ**: フッターの `-3deg` 回転枠 + 最上部の黄色帯（常時表示・絶対条件）

## モーション

- ロード時: hero 要素の staggered rise（0.7s, 80ms 刻み）のみ
- LIVE インジケータ: `●` の blink（1.2s steps(2)）
- ホバー: タイムライン行の `translateX(4px)` + ボーダー黄変、CTAの `translate(-2px,-2px)` + ハードシャドウ
- **`prefers-reduced-motion: reduce` で全アニメーション無効**（カンプに実装済み。必ず移植）

## レスポンシブ

- ブレークポイント 720px 一つで足りる（2カラム→1カラム）
- 見出しは `clamp()` で流動化済み。375px で横スクロール禁止（受け入れ条件）

このサイトはダーク単一テーマ（HUDコンセプトのため）。ライトテーマは作らない。
